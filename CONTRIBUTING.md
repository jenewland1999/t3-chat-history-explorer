# Contributing

Thanks for your interest in contributing.

This project started as a personal utility, but improvements are welcome.

## Getting started

1. Fork the repository
2. Create a branch from `main`
3. Install dependencies:

```bash
bun install
```

4. Run tests:

```bash
bun test
```

5. Run the CLI locally against your export file to validate behavior

## Pull request guidelines

- Keep changes focused and minimal
- Include clear reproduction steps for bug fixes
- Update documentation when behavior or CLI flags change
- Ensure tests pass before opening a PR

## Reporting issues

Use the issue templates for bug reports and feature requests.

## Code of conduct

Please be respectful and constructive in discussions.
